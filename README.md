# ☕ Coffee Machine

A Python-based Coffee Machine project built in **two different approaches**: Procedural Programming and Object-Oriented Programming (OOP).

## 📌 About the Project

This project simulates a simple coffee machine where users can select drinks, make payments, and purchase coffee while the machine manages available resources.

I implemented the same project in two different ways to understand the difference between **procedural programming** and **Object-Oriented Programming**.

## 🔹 Version 1: Procedural Programming

The first version uses basic Python programming concepts such as:

- Variables and data types
- Dictionaries
- Functions
- `if-else` statements
- `while` loops
- User input
- Resource management

This version focuses on solving the problem using functions and procedural logic.

## 🔹 Version 2: Object-Oriented Programming

The second version is built using OOP concepts to make the program more modular and organized.

It uses:

- Classes
- Objects
- Methods
- Constructors (`__init__`)
- Encapsulation
- Modular programming

The functionality is divided into different classes instead of keeping everything in one procedural program.
